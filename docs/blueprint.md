# **App Name**: AnonyCollab

## Core Features:

- Secure User Management: User authentication and role management for secure access.
- Interactive Post Dashboard: Interactive dashboard for displaying posts and filtering by tags and sector.
- AI Connection Matcher: AI powered tool to suggest relevant connections based on post content and user profiles for enhanced collaboration matching.

## Style Guidelines:

- Primary color palette using soft sky blue tones to convey trust.
- Neutral background colors (e.g., light grays and whites) to ensure content readability.
- Accent color: Teal (#008080) for interactive elements and highlights.
- Card-based layout for posts to present information in an organized manner.
- Sliding side panel for detailed post views to maintain context without page transitions.
- Use a consistent set of icons for sectors, business types, and safety indicators.
- Subtle animations for panel transitions and interactive elements to enhance user experience.

## Original User Request:
Prompt: Web Application Design for B2B Anonymous Collaboration Platform
Overview:
Design a modern and clean web application interface for a platform where businesses can collaborate anonymously. The platform includes features like post boards, sector-based help tags, AI matching, and anonymous business profiles with verifiable reputation.

💡 Key Requirements:
🔐 User Signup Page
Input fields:

Company Name

Email Address

Password

Option: “Sign up with Google”

Dropdown: Select Industry (Tech, Retail, Logistics, etc.)

Upon signup → redirect to Home Dashboard

🏠 Homepage (After Login)
Top Navigation Bar Tabs:

BOARD | INVEST | CONNECT | CONTRACTS

Sub-filters / Tag Buttons under BOARD:

LEGAL, PRODUCT, SUPPLIER, COLLABORATION, MARKETING, ADS, AUDIENCE

📃 Post Feed (Main Section)
Posts displayed in a card layout

Each card shows:

Tags at top (e.g. LEGAL, PRODUCT)

Short question/need (e.g. “How to get copyright-free product images?”)

Clicking a card opens a sliding panel from the right

🧾 Post Detail Side Panel (Slide-In View)
Business remains Anonymous

Shows:

Sector (e.g. Tech Sector)

Business Type (Startup, Growing, etc.)

Safety Indicator / Badge

Rating Score or Trust Level

Business Stock Graph (basic line chart for visual trust insight)

🎨 Style Guidelines
Clean, soft color palette (sky blue tones)

Rounded corners, smooth shadows

Font: Simple and modern (e.g., Inter, Roboto)

Minimal clutter; tag-based filtering for simplicity

🔄 Functional Behavior
Post creation: via form that includes title, description, tag selection

Right panel dynamically updates when post is clicked

All personal business data stays hidden unless a contract is signed
